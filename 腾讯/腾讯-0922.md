## 二、9 月最重要的增量变化（旧报告之后）

### ⭐ 变化 1：Meta Muse 爆火 → 消费级 Agent 价值重估，腾讯成"中国版 Muse"首选映射（9/22）

- **Muse 的范式跃迁（中金梳理四点）：** ①后台异步执行、跨对话长期记忆；②真实账户连接（邮件/日历/支付/电商/智能家居，连接器 + 公开 API + 浏览器操作三类）；③独立 Secure VM + Sentinel 审批门控的安全架构；④Ideas/Feed 显露"推荐式 Agent"雏形——从等用户提问转向主动识别需求。
- **商业模式：** 免费层 + 20/100 美元两档月费，未来有望走向"订阅打底 + 交易抽佣"。
- **为何腾讯是最优对标：** 微信已将**账户、社交关系、小程序服务生态、微信支付闭环**整合于平台内部，自有 Agent 可在授权范围内直接调用能力、完成交易；相比之下 Meta 海外服务入口分散、需大量浏览器操作覆盖长尾，连接与维护成本更高。
- **大摩消费 AI TAM（9 月研报）：** 中国消费端 AI 可变现收入约 **540 亿元（2026）→ 2,940 亿元（2030）→ 1.6 万亿元（2040 基准情景）**；收入高度偏向商家端（2030 交易佣金约 2,810 亿，广告 + 佣金占 99%），腾讯、阿里被列为核心受益方，逻辑是"超级 App 分发 + 免费入口 + 移动支付 + 商家履约"。

### ⭐ 变化 2：WorkBuddy 开放平台上线，定位"Agent 时代的操作系统"（9/2）

- 腾讯把智能体底层能力开放给**硬件厂商、行业应用与开发者**：首批伙伴 **100+ 家、9 款联名智能硬件首发**（Plaud、Rokid、影石 Insta360、科大讯飞、安克等 30 余品牌接入"听/看/记/聊/协"五类触点）。
- 行业伙伴首批 30 余个 Buddy 应用（金融、法律、医疗、教育等 20 多领域）；开发者获得 **Skill / Expert / Connector** 三类接口，并支持 **MCP 与 CLI**——腾讯不争协议标准，要的是所有协议跑在自己的账号体系、分发网络与**工作记忆库**上。
- **护城河逻辑（高盛峰会复述）：** 规模经济 + WorkBuddy/CodeBuddy 专有反馈闭环（真实任务数据回流训模型）+ 模型/基础设施/芯片全栈协同。CodeBuddy 已覆盖腾讯内部 95% 工程师、编码时间缩短 40%。

## 六、主要风险

1. **AI 投入回报错配：** 2026 全年资本开支约 2,100 亿+，FCF 转正时点（市场预期 2027 趋稳）若继续后移，估值中枢承压；资产属性由轻转重的定价切换尚未完成。
2. **折旧侵蚀利润：** 2026–2028 核心净利预测被多家券商下调 2%–9%，2026/2027 增速仅约 2%–3%。
3. **消费级 Agent 落地不及预期：** 小微 Q4 全面推广存在合作与监管不确定性；元宝月活、WorkBuddy 付费转化仍需数据验证；QuestMobile 显示 AI 效率办公用户增速已放缓（7 月 MAU 同比仅 +8.2%，但使用次数 +112%），竞争转向使用深度。
4. **监管周期：** 平台货币化、数据采集、Agent 调用交易的合规边界仍在演进；9 月 OTA 立案等事件显示常态化监管延续（虽主要涉美团/飞猪等，但行业情绪联动）。
5. **游戏结构性短板：** 国际游戏受汇率与 Supercell 高基数拖累、QQ 月活持续下滑；版号与竞品（字节/网易）节奏影响长线流水。
6. **技术面：** 9/22 大涨前股价长期位于主要均线下方；单日情绪驱动的跳空缺口需回补确认，若后续量能不济存在反复。

### 2. 结论

- **基本面：** 旧报告"低估 + AI 期权"的判断成立，且 9 月补齐了两个关键缺口——AI 现金消耗**可见终点**（一次性大额预付而非逐年刚性）与应用层**生态闭环**（WorkBuddy 开放平台 + 小微 Q4 推广）。9/22 的 Muse 映射是情绪与估值重估的起点而非终点。
- **节奏：** 短空中概互联的核心矛盾从"AI 烧不烧钱"切换为"AI 何时确认收入/FCF 何时转正"。在 2026–2027 盈利增速被折旧压至 0%–3% 的背景下，股价上行更依赖**估值倍数修复**（13 倍 → 历史 18–20 倍），催化集中在 Q4：小微全面推广、Hy4 发布、广告持续 20%+。
- **风险收益比：** 一致目标价 664（+45%）、强力推荐占比 79%，下方有 411–430 支撑区、4,872 亿上市股权与强现金流托底；中期赔率仍明显占优。
